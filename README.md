# DSA Solutions

My solutions to data structures and algorithms problems, written in C++ and organised by topic.

## Topics
- Arrays
- Strings
- Linked lists
- Stacks and queues
- Recursion and backtracking
- Trees
- Sorting and searching

## How I organise this repo
Each topic has its own folder. 
Each file is one problem, named after the problem. 
At the top of every file I note the platform, the approach, and the time and space complexity.
