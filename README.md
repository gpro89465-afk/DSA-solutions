## Repository structure

Each topic has its own folder, and each file is one problem:

    arrays/
      two-sum.cpp
    strings/
    linked-lists/
    ...

## How to run a solution

You need a C++ compiler such as g++.

    g++ arrays/two-sum.cpp -o two-sum
    ./two-sum

On Windows, run `two-sum.exe` instead of `./two-sum`.

## File format

Every solution starts with a short comment block:

    // Problem: <name and platform, e.g. LeetCode 1>
    // Approach: <one line on the idea>
    // Time: O(...)   Space: O(...)
